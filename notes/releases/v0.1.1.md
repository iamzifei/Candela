A small release: the app is now usable with a screen reader, and it has a proper
macOS 26 icon.

### VoiceOver

Six switches had no name. Show Combined Brightness, Show Volume Sliders, Launch at
Login, Smooth scaling, HDR and Extra Brightness were each announced as an unnamed
checkbox — a screen-reader user heard the state without ever hearing what it was.

Rows were announced two and three times over: the label was landing on every text
element inside a row rather than on the row itself, so "Resolution, collapsed" came
through three times with no way to tell the copies apart.

And both brightness sliders were called "Display brightness", which on a
two-monitor desk names neither of them. They now carry the display's name, as does
the volume slider.

### Icon

A layered icon, so macOS 26 lights it rather than pasting it: the arc refracts, the
centre reads as its own lens, and it renders correctly in the tinted and clear
appearances as well as light and dark.

This also fixes Candela showing a grey placeholder in System Settings > Privacy &
Security > Accessibility. The cause was not the icon in /Applications, which was
always fine — LaunchServices resolves an app by its bundle identifier, and a test
build sitting in DerivedData had registered the same identifier while carrying an
empty icon slot. Both build paths now produce the same icon, so it does not matter
which copy the system finds.

### Also

Nothing else changed for anyone using the app. Internally the display-mode view was
split into three files and the lint thresholds were tightened to what the code
actually does, so neither can quietly drift.
