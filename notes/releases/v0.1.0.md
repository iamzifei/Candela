Candela is a menu bar app that gives external monitors on a Mac the controls the
system keeps for the built-in screen.

**Brightness that reaches the backlight.** DDC/CI over the video cable, the same
channel the monitor's own buttons use. A display that refuses DDC falls back to
gamma dimming and is marked *Software* in the panel, so "brightness works but looks
wrong" is visible rather than mysterious.

**Brightness keys on any display.** F1 and F2 can follow the pointer, drive every
display, drive them all as one, or drive only the ones you pick.

**Sharp HiDPI scaling.** The 2×-rendered modes macOS hides on third-party monitors,
so a 1440p or 4K panel can be readable *and* sharp instead of one or the other.

**Displays that match each other.** One slider for the whole desk, plus a floor you
calibrate by eye per display — because sending two panels the same percentage does
not make them emit the same light, and at the bottom of the range one goes black
while its neighbour is still lit.

**And:** resolution and refresh rate, display arrangement, colour profiles, presets,
virtual displays, iPad over Sidecar, HDR and extra brightness, DDC volume,
keep-awake, Dark Mode and Night Shift.

Interface in English, 简体中文 and 繁體中文.

### Install

```
brew install --cask iamzifei/tap/candela
```

Or download the DMG below. Signed with a Developer ID and notarised by Apple, so it
opens without right-click warnings.

### Requirements

- macOS 26 or later
- Apple silicon
- For hardware brightness: DDC/CI enabled in the monitor's own on-screen menu. Most
  ship with it on; a few, and some USB-C docks, do not pass the channel through.

### Origin

A fork of [Crisp](https://github.com/didriksg/Crisp) by Didrik Galteland, itself
descended from [FreeDisplay](https://github.com/huberdf/FreeDisplay). Both MIT, as
is this.
