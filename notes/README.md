# notes

Developer documentation, design doctrine, and plan files.

These are here rather than in `docs/` for one reason: `docs/` is the directory
GitHub Pages publishes. Anything placed there is served — the design doctrine, the
build guide and the plan files were all reachable at
`https://zifei.info/Candela/DESIGN.md` and friends, and the plan files in
particular are working documents that were never written to be read by anyone
passing by.

This is a deliberate departure from the usual `docs/plans/` convention, forced by
the folder collision. If the site ever moves to a custom Pages workflow that can
publish from somewhere else, `docs/` frees up and these can move back.
