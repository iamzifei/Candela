# Candela — notes for coding agents

## Website (getcandela.app)
- `docs/` is **generated**. GitHub Pages serves it as-is, but it is built by `site/build.py` from `site/content/*.md` (8 languages) and the templates inside `build.py`.
- **Never edit `docs/` by hand.** Edit `site/content/` or `site/build.py`, run `python3 site/build.py`, and commit `docs/` together with the source change.
- `python3 site/build.py --check` must print `docs/ matches site/content`; the "Site in sync" workflow fails otherwise.
- Every generated page starts with a `GENERATED by site/build.py` comment as a reminder.
